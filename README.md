# Java-Pattern-Printing

Each file in `JavaPatternPrinting/` is a standalone console program. Run one
source file at a time with JDK 11 or later. Several examples reuse the class
name `main`, so compiling the entire directory together causes duplicate-class
errors.

To try the solid rectangle, run these commands from the repository root:

```sh
java JavaPatternPrinting/SolidRectangle.java
```

Enter `2 3` for two rows and three columns. The program prints:

```text
* * *
* * *
```
